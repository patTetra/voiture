Export

Importer dans Première Pro Séquence PNG (ZIP) :
  1. Double-clique sur le ZIP pour le décompresser.
  2. Fichier ▸ Importer (Cmd + I), entre dans le dossier et clique une seule fois sur la 1ʳᵉ image.
  3. Coche Séquence d'images en bas de la fenêtre (bouton Options si besoin), puis Importer.
  4. Clic droit sur le clip dans le panneau Projet ▸ Modifier ▸ Interpréter le métrage : Conformer à 25 (ou 30).
  5. Glisse le clip sur la piste au-dessus de ta vidéo.
Choisis une définition égale à celle de ta séquence (3840 × 2160 pour du 4K).
